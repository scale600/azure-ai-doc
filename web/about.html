✦ AI-First Document Processing

An AI-first pipeline for financial documents

This service prototype automates what used to be slow, manual document review. It classifies, extracts, and summarizes KYC identity documents, invoices, and service applications — and it does so with AI at every meaningful step.

The AI core

The system is built around two Azure AI services working together:

Azure AI Document Intelligence is the "reader". It performs OCR and structured field extraction using prebuilt models (prebuilt-idDocument, prebuilt-invoice, prebuilt-read), turning an image or PDF into structured text and fields with confidence scores.

Azure OpenAI (gpt-4.1-mini) is the "reasoner". It reads the extracted text and fields, then classifies the document, writes a natural-language summary, detects risk signals and missing fields, and produces a confidence score — all returned as strict, validated JSON.

Together they replace the manual work of reading, classifying, and flagging documents: upload in, structured intelligence out.

What it does

  • Classifies documents into types (KYC ID, invoice, application).
  • Extracts key fields with confidence.
  • Summarizes content in natural language.
  • Detects risks (expirations, anomalies) and missing fields.
  • Visualizes the whole process live on a dashboard.

Technology stack

Azure AI Document Intelligence

OCR and field extraction via prebuilt models.

Azure OpenAI · gpt-4.1-mini

Classification, summarization, risk and missing-field detection.

Azure Functions

Serverless Python pipeline triggered by blob events.

Azure SQL & Blob Storage

Structured results and source documents.

Key Vault + Managed Identity

Secrets are never in code; access is identity-based.

Static Web App

The dashboard front-end.

Terraform

Infrastructure as code.

GitHub Actions

CI/CD with OIDC authentication.
